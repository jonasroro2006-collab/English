# English Jonas V1

Application PWA d'apprentissage de l'anglais A1→C2, conçue pour fonctionner hors ligne.

## Fichiers

* index.html : structure de l'application
* style.css : design responsive
* app.js : cours, exercices, progression et stockage local
* manifest.json : installation PWA
* service-worker.js : cache hors ligne

## Installation GitHub Pages

1. Créer un dépôt GitHub.
2. Envoyer les 5 fichiers à la racine.
3. Settings → Pages → Deploy from branch → main / root.
4. Ouvrir l'adresse Pages et installer l'application depuis le navigateur.

## Important

Les données sont stockées dans localStorage sur l'appareil. Aucun compte ou serveur n'est requis dans cette V1.
